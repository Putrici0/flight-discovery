# Data Sources

Fuentes de datos previstas para evaluar mas adelante. Todavia no hay integraciones implementadas.

## Aeropuertos

- Listados de aeropuertos y aerodromos.
- Coordenadas, elevacion, pistas y codigos ICAO/IATA cuando existan.
- Restricciones operativas basicas si estan disponibles.

## Meteorologia

- METAR/TAF cuando esten disponibles.
- Viento, visibilidad, techo de nubes y fenomenos relevantes.
- Datos simplificados para una primera version si no hay integracion completa.

## Aviones

- Perfiles definidos por el usuario.
- Velocidad de crucero.
- Consumo estimado.
- Combustible utilizable.
- Margen de reserva configurable.

## Rutas

- Distancia entre aeropuertos.
- Tiempo estimado en ruta.
- Viabilidad por combustible y tiempo disponible.
- Preferencias como paisaje, costa, montana, islas o aeropuertos concretos.
