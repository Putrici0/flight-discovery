# Idea

Flight Discovery ayuda a pilotos recreativos a encontrar rutas de vuelo interesantes y realistas sin tener que comparar manualmente aeropuertos, tiempos, combustible y condiciones basicas.

## Problema

Planificar un vuelo recreativo requiere revisar alcance del avion, autonomia, meteorologia, aeropuertos adecuados y preferencias personales. Ese proceso puede ser lento incluso para vuelos sencillos.

## Propuesta

Una web responsive donde el usuario introduce:

- Aeropuerto de salida.
- Tiempo disponible.
- Tipo o modelo de avion.
- Combustible disponible o autonomia.
- Meteorologia basica.
- Preferencias de ruta.

El sistema devuelve rutas candidatas con informacion clara para comparar opciones.
